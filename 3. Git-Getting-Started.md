### Git Install
 - You can download from [here](https://www.git-scm.com/)

 ### Getting Started with Git
  - To check if Git is proplerly installed in your computer, Run

```bash
git --version
```
 - Once you have written this code in your terminal, run it and you will see the version of Git if it is installed.

 e.g 
 ```bash
 git version X.Y
 ```

 ### Configure Git
 - Now we need to let Git know who you are, which is important for version control, because Git uses this information to store your information.

 ```bash
 it config --global user.name "your_github_username"
git config --global user.email "email"
```

### Creating Git folder

```bash
mkdir project1
cd project1
```
mkdir - makes a new directory
cd -  changes the current working directory

### Initializing Git
- Once you have navigated Git into the folder , lets initialize it,
```bash
git init
```
 - This creates an empty Git Repository in your folder

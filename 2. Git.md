# What is Git
Git is a version control system, which was created by Linus Torvalds in 2005, and has been maintained by Junio Hamano.

Git is used for:
 - Tracking code changes.
 - Tracking who made the code changes.
 - Coding collaboration.

## What does Git do?
 - Organize your work using repositories
 - Create a local copy by cloning a project
 - Track and manage changes through staging and committing
 - Use branching and merging to work on different features or versions
 - Update your local copy by pulling the latest changes
 - Upload your local changes to the main repository by pushing

 ## Working with Git
  - Initialize Git into a folder, which makes it a <strong> Repository <strong>
  - Git now creates a hidden folder, where it keeps a track of the changes in that folder
  - When a file os changed, added or deleted, it is considered <strong> modified<strong>
  - You are in control to select the modified files you want to <strong>stage<strong>
  - Committing staged files saves a permanent snapshot in Git
  - Git maintains a complete history of all commits
  - You can roll back to any previous commit if needed
  - Instead of saving full copies, Git tracks changes made in each commit

## Why Git?
 - Over 70% of developers use Git!
 - Developers can collaborate remotely from any location
 - The entire project history is accessible to all developers
 - Previous versions of the project can be restored when needed

 ## What is Github?
 - GitHub is the largest host of source code in the world, and has been owned by Microsoft since 2018.
